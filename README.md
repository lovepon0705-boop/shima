# СТО Шима — Лида

Одностраничный сайт автосервиса. Данные взяты из карточки организации на Яндекс Картах.

## Запуск
Откройте `index.html` в браузере. Фото подгружаются по ссылкам Яндекса, нужен интернет.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите содержимое папки.
2. Settings → Pages → Source: **GitHub Actions**.
3. После пуша в `main` сайт опубликуется автоматически.
